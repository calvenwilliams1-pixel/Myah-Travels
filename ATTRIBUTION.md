# Attributions

Static data shipped in `data/` is sourced from public datasets. Attribution is required for some.

## Airports (`data/airports.json`)

Source: **OurAirports** — https://ourairports.com/data/
License: Public Domain
No attribution required, listed here for provenance.

## Airlines (`data/airlines.json`)

Source: **OpenFlights** — https://openflights.org/data.html
License: Open Database License (ODbL)
Attribution required. Airline data derived from the OpenFlights project.

## Regeneration

Both files are regenerated by `scripts/fetch-static-data.js`. Run manually when a refresh is wanted. Committed snapshots are marked `_generated: false` when they are development seeds rather than full datasets.
